### To Run Demonstration
1. Activate virtual environment and run pip install -r requirements.txt
2. Run pca_demo.py

> [!WARNING]
> uv option has been included; however, not functioning as expected as of now. Since numpy is the only dependency, the default process should be just as effective.

> [!NOTE]
> The pca_flow.ipynb file is included for a segrated output per code block pertaining to the demonstration.
